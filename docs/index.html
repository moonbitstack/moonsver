What it does

Six things, done once

A version is a small, strict format. The work is in the edges: leading zeroes, prerelease ordering, build metadata, and the many ways a range can be written.

Arbitrary precision

The three numbers are BigInt. 18446744073709551616.0.0 parses, prints and compares exactly.

One parser, four grammars

npm, Cargo, Ruby and the strict standard are a setting on Syntax, not four forks of the parser.

Ranges are structure

^1.2.3 expands to >=1.2.3, <2.0.0. Read the sets back, or ask which versions fit.

Precedence per §11

Numeric identifiers before alphanumeric, a shorter list below a longer one, build metadata left out.

Bumps that match

Major, minor, patch and the prerelease corners that are easy to miss, including 1.0.0-pre → 1.0.0.

JSON in and out

Version and Range serialise as strings, so they drop straight into config files and API responses.

One string, four grammars

The same range, read four ways

Ranges are not in the standard, so each ecosystem wrote its own. Type one and see how npm, Cargo, Ruby and the strict grammar each expand it — live, through the compiled library.
